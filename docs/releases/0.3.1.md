# FerryDesk 0.3.1

## 简体中文

### 修复

- 修复扩展屏窗口刷新时回传屏幕中央的旧鼠标坐标，导致光标反复弹回、无法自由移动。
- 防止注入输入经扩展窗口回传，并修正隐藏光标恢复与定时定位行为。
- 恢复反向扩展时进入来源电脑实体屏幕的跨屏通道。

## English

### Fixed

- Fixed display window refreshes sending a stationary receiver pointer back to the source, causing repeated pointer snap-back.
- Prevented injected input from being echoed through the display receiver and corrected cursor hiding and periodic positioning.
- Restored edge switching to the source computer's physical screen during reverse display extension.
