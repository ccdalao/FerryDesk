# FerryDesk 0.3.0

## 简体中文

### 新增

- FerryDesk 品牌界面与青绿色高对比主题。
- Windows 双机扩展屏输入会话独占控制权，停止扩展后恢复普通键鼠共享。

### 改进

- 扩展屏安装包升级到 0.3.0，保留已有 ScreenFerry 命令和数据目录。

### 修复

- 修复扩展屏使用期间鼠标反复进入和退出远端、回到停靠点的问题。
- 修复隐藏光标停靠点被桌面合成显示的问题。

## English

### New

- FerryDesk branding with a high-contrast teal interface theme.
- Extension input owns the paired pointer while the Windows display extension is active, then returns control to ordinary sharing when it stops.

### Improved

- Windows installer version 0.3.0 keeps existing ScreenFerry commands and data directories.

### Fixed

- Fixed repeated remote Enter/Leave transitions and pointer jumps during display extension.
- Fixed the hidden cursor parking point appearing in the desktop composition.
