# Windows 副屏方案验证（2026-11-15）

## 使用

两台安装同一新构建。打开“设备 → 对方电脑 → 副屏方案 → 新建方案”，填写名称，选择桌面来源电脑、两端实体屏、Windows 主显示器、接收屏相对于来源屏的位置、声音与快捷键。保存后点“应用方案”，或用托盘“扩展屏 → 方案”及对应快捷键；取消仍用现有“取消副屏拓展”。方案保存在创建它的电脑上，快捷键为 Ctrl+Alt+Shift+数字，且与已有操作不能重复。Windows 屏幕重新编号时需要重选。

## 故障依据与修复

本机旧日志中出现管理员前台输入被拒，以及 `DXGI 未找到本次虚拟显示输出`。后者在重建捕获时直接终止媒体会话，现改为暂用既有备用捕获并每 250 ms 重试。输入坐标读取 Windows 当前模式，不依赖可能陈旧的 DXGI 输出位置。

此前虚拟屏固定放在右侧，普通键鼠布局却可能把来源电脑放在另一边。新方案通过 Windows CCD 提交完整布局，并同步拓展期间的鼠标入口；原普通布局不写回。对等连接还会报告最新位置供默认操作使用。

主屏变更使用 Windows 当前路径和模式表；单独用 GDI 暂存物理主屏的尝试在本机被驱动拒绝，已从最终实现中移除。原主屏与位置在本机用户的显示事务记录中保留，恢复成功后删除。异常退出恢复实测已通过。

## 仍需两台电脑验收

本机实测和模拟双机测试不等同于实际双机窗口拖动已验收。升级后先从被控端应用方案，确认主控显示扩展桌面；分别从左、右、上、下拖动同一桌面的记事本窗口，确认方向与鼠标一致；切换主屏、连续换向并取消，检查原布局和鼠标恢复。管理员窗口继续需要两端启用管理员后台，UAC 使用原授权服务；副屏视频不采集安全桌面。
