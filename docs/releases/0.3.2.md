# FerryDesk 0.3.2

## 简体中文

### 修复

- Windows 主程序默认安装目录改为 FerryDesk，升级后同步更新开机启动位置。
- 窗口左上角显示 FerryDesk，个人构建可在名称下显示小字标记。
- Windows 窗口标题和设置程序的文件属性统一显示 FerryDesk。

## English

### Fixed

- Changed the default Windows application folder to FerryDesk and updated the startup command during upgrades.
- Displayed FerryDesk in the upper-left corner, with an optional personal build label below it.
- Updated the Windows window title and settings application file properties to FerryDesk.
