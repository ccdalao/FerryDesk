# FerryDesk 0.4.0

## 简体中文

### 新增

- “被控电脑屏幕扩展主控”时，可将主控电脑声音传输到被控电脑的默认扬声器播放；反向扩展同样支持。

### 改进

- 音频开关文案明确显示声音从来源电脑到接收电脑扬声器的方向。
- 音频设备不可用时保留视频扩展，并在日志中说明原因，避免整个扩展会话被声音设备阻断。
- 音频播放使用短时有界缓冲，网络短暂抖动时减少爆音和断续。
- 重复的输入隐藏/抓取/释放请求不会把鼠标再次移到主屏中央；异常回收时回到最近实体屏边界。

## English

### New

- Display extension can play the controller's audio through the controlled PC speakers when the controlled PC extends the controller; the reverse direction is supported too.

### Improved

- The audio setting now explains the source-to-receiver speaker direction.
- A missing or unavailable audio device no longer stops video extension; the reason is recorded in the log.
- A short bounded audio buffer reduces pops and gaps during brief network jitter.
- Repeated input hide, grab, or release requests no longer warp the pointer to the primary-screen center; recovery returns it to the nearest physical screen edge.
